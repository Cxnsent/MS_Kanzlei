Hinweis zur Einbindung

Die Höhe der IFrame-Flächen wird über min-height gesteuert. Für sehr lange Forms-Formulare kannst du im CSS .embed-frame-wrap.forms erhöhen, zum Beispiel auf 1000px.

Für Bookings gilt entsprechend .embed-frame-wrap.bookings.

Unterseiten innerhalb einer Datei

Da alles in einer HTML-Datei bleibt, werden Unterseiten per Sprungmarke simuliert. Das reicht für eine Demo und bleibt technisch simpel.
