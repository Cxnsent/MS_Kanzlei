Variante A · Button-Lösung

Button-Lösung für Microsoft Forms und Bookings

Diese Variante ist technisch am saubersten, weil Microsoft Forms und Microsoft Bookings vollständig in ihrer eigenen Oberfläche laufen. Der Nachteil: Der Nutzer verlässt für den Vorgang die Kanzleiseite.

Stabilste Variante
Microsoft Forms
F

Mandantenformular öffnen

Das Formular wird per Button geöffnet. So gibt es keine abgeschnittenen Inhalte, keine IFrame-Höhenprobleme und keine künstlichen Scrollbereiche.

  • Mandant klickt auf den Button
  • Microsoft Forms öffnet vollständig
  • Formular kann sauber ausgefüllt werden
Formular öffnen

Technisch sauber, aber nicht innerhalb der Kanzleiseite.

Microsoft Bookings
B

Terminbuchung öffnen

Der Buchungskalender wird über einen Button geöffnet. Das ist für Bookings oft besser, weil Microsoft die Bedienoberfläche selbst kontrolliert.

  • Mandant klickt auf Terminbuchung
  • Bookings öffnet vollständig
  • Termin kann ohne Einbettungsprobleme gebucht werden
Termin buchen

Technisch sauber, aber nicht innerhalb der Kanzleiseite.
